# fw_1541 deviation register

Core 1 ("1541" drive) firmware of IronKernel 64 (no RTOS: lwIP NO_SYS=1, superloop
src/main.c, built by build.ps1). This register lists every
place where the firmware departs from vendor or third-party code as shipped,
or from a rule of `embedded_ccoding.md`. Each site carries the literal tag
`IK64_DEVIATION <n>`, so `grep -rn IK64_DEVIATION fw_1541` gives the complete
map. Unmodified third-party trees (`third_party/libsmb2`, the AMD lwIP 2.2.0
install) carry no tags; nothing in them is edited. Each deviation is a build
flag, a configuration header, or a project file that stands in for a vendor file.

The network glue (bring-up, link and lease monitor, lwIP start, platform services; rows 8 and 10)
is part of the prebuilt library `lib/libik64_netcore.a` (row 12).

Third-party versions: libsmb2 commit `a52c1571` (`third_party/libsmb2/SOURCE.txt`), lwIP 2.2.0 from
`C:\AMDDesignTools\2026.1\Vitis\data\embeddedsw\ThirdParty\sw_services\lwip220_v1_4`.
